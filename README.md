 # DMAS-CALCURATOR-FOR-UNO-R4-WIFI-AND-OTHER-BOARDS
This code runs a to-decimal calculator that can handle arthematic problems like Addition, Subtraction, Multiplication and Division on the UNO R4 WIFI and other advanced Arduino boards

You can interact with it through Serial Monitor.

This Calculator features:

-DMAS sequence of computing numbers

-Has a watchdog to prevent the board from crashing due to overloaded input

-Can solve basic questions like 9 + 5 and equations like 4 x 4 / [9 + {8 + (2 * 3)} - 1] using bracket sequencing

-uses + for addition , - for substraction, * for multiplication and / for division

-bracket solving syntax : [] - outermost, {} - middle and () - innermost

-bracket solving sequence : solves ()-first, then {}-second and [] - third
